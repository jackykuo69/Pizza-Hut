# COC 商圈活動設計引導工具｜V18

## 本版重點

1. 本版以 V17 為基礎。
2. Step 3｜Q3「可以形成什麼相對價值，或應該如何降低影響？」改為更順口的實務判斷語氣：
   - 不期待……，而聚焦在……
3. 這樣可以避免學員以為要改變不能改的條件，而是把注意力放在可以設計、可以處理、可以行動的地方。
4. 保留 V17 的 Step 3｜Q2 修正：
   - 顧客不容易自然想到我們
   - 顧客覺得不方便到店或取餐
   - 活動要設計在店外、取餐前後或外部場域
   - 需要靠社區、商場、學校或地方合作接觸顧客
5. 保留：
   - Step 1 先定 TA，再判斷情境、需求痛點與選擇理由
   - Step 3 處理條件與限制、造成的影響、相對價值或降低影響
   - 後台只保存完成第四階段後的有效資料
   - Q3 顧客單選
   - 其他欄位
   - 候選行動編號直接點選
   - COC 商圈活動脈絡策劃表
   - Action Design 表
   - PDF 匯出／列印
   - Pizza Hut logo
   - 後台查看／刪除／下載 CSV
   - D1 資料庫架構
