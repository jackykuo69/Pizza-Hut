# COC 商圈活動設計引導工具｜V24

## 本版重點

1. 本版以 V23 為基礎。
2. 針對方案評估表分數讀取 bug 再次修正：
   - 已選 1／3／5 分後，系統會正確讀取分數。
   - 總分欄應立即顯示數字。
   - 按下「整理成 Action Design」前會重新計算分數。
3. 分數讀取採雙保險：
   - 先讀內部評分資料。
   - 若內部資料未更新，直接讀目前畫面已勾選的 radio。
4. 當選邏輯維持：
   - 先比較總分。
   - 若總分相同，依序比較：效益 → 可行性 → 成本 → 風險性 → 測試性。
   - 若所有分數完全相同，才由使用者人工選定一個方案。
5. 保留 V23 功能：
   - 候選行動依 COC 情境篩選，不固定湊滿 5 個。
   - 使用者選定的所有候選行動都會進入方案評估。
   - 至少選 2 個候選行動。
   - 按「確認候選行動，進入方案評估」後才顯示評估表。
   - 最終只產出一個當選方案。
   - 後台只保存完成第四階段後的有效資料。
