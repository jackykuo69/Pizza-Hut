# COC 商圈活動設計引導工具｜V21

## 本版重點

1. 本版以 V20 為基礎。
2. 方案評估表的五個構面都補上明確評分判準：
   - 效益：對銷售、來客、回訪、名單蒐集或商圈接觸的幫助越明顯，分數越高。
   - 可行性：依現有人力、流程、技能與品牌規範越容易執行，分數越高。
   - 成本：所需時間、人力、物料、贈品或費用越低，分數越高。
   - 風險性：對取餐、外送、食品安全、顧客體驗或品牌規範造成的風險越低，分數越高。
   - 測試性：能否先用單一時段、少量名額、少量物料、單一合作點或小範圍顧客試行；越容易先小規模測試並調整，分數越高。
3. 測試性強調單店也可以做小規模測試，例如單一時段、少量名額、單一合作點或小範圍顧客。
4. 保留 V20 功能：
   - Step 4 自動產出候選行動
   - 2–3 個候選行動進入方案評估
   - 評分採 1／3／5 分
   - 同分時依序比較：效益 → 可行性 → 成本 → 風險性 → 測試性
   - 最終只產出一個當選方案
   - COC 商圈活動脈絡策劃表
   - Action Design 表
   - PDF 匯出／列印
   - Pizza Hut logo
   - 後台查看／刪除／下載 CSV
   - 後台只保存完成第四階段後的有效資料
