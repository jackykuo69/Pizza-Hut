# COC 商圈活動設計引導工具｜V26

## 本版重點

1. 本版以 V25 為基礎。
2. Step 1｜Q1 顧客選項加入定義：
   - 每個顧客選項都呈現「顧客類型＋小字定義」。
   - 定義涵蓋 R1、COM、Sub 及各第二層細分情境會出現的顧客類型。
3. Step 1｜Q1 上方說明簡化：
   - 請單選本次活動最想優先服務的一類顧客。請聚焦一類主要顧客，不要一次服務所有顧客。
4. Step 1｜Q4 改成顧客視角：
   - 可以預購、外帶或外送，不一定要現場等待。
   - 在原本活動場域就能接觸或購買，不必特地繞路。
5. Step 4｜候選行動表移除「建議判斷」欄位。
6. Step 4｜方案評估表調整欄寬，讓效益、可行性、成本、風險性、測試性五個構面較平均。
7. 保留 V25 的重要修正：
   - 分數讀取以畫面已勾選 radio 優先。
   - 按「整理成 Action Design」前會重新計算分數。
   - 新增「重新計算分數」按鈕。
   - 至少選 2 個候選行動。
   - 同分時依序比較：效益 → 可行性 → 成本 → 風險性 → 測試性。
   - 完全同分才由使用者人工選定一個方案。
   - 後台只保存完成第四階段後的有效資料。
