# COC 商圈活動設計引導工具｜V16

## 本版重點

1. Step 1 只處理顧客：
   - 先定 TA
   - 再判斷出現情境
   - 再判斷需求與痛點
   - 最後判斷為什麼可能選擇我們
2. Step 1 不再詢問門市條件或限制。
3. Step 3 專門處理商圈條件與限制：
   - 條件與限制
   - 對顧客或活動造成的影響
   - 相對價值或降低影響的處理方向
4. 最終 COC 表已同步調整欄位內容。
5. 後台仍只保存完成第四階段後的有效資料。
6. 保留：
   - Q3 顧客單選
   - 動態顧客說明
   - 其他欄位
   - 候選行動編號直接點選
   - COC 商圈活動脈絡策劃表
   - Action Design 表
   - PDF 匯出／列印
   - Pizza Hut logo
   - 後台查看／刪除／下載 CSV
   - D1 資料庫架構
