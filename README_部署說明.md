# COC 商圈活動設計引導工具｜V22

## 本版重點

1. 本版以 V21 為基礎。
2. Step 4 候選行動改為依 COC 情境篩選，不固定湊滿 5 個。
3. 明顯不適配的活動會被排除。例如選擇「醫院／診所周邊」與「陪診或陪伴家屬」時，候選行動會偏向快速取餐、預購外帶、陪伴輪替與外部接觸點提醒，不會出現親子挑戰或戰鬥陀螺類活動。
4. 使用者選定的所有候選行動都會進入方案評估，不再限制最多 3 個。
5. 仍保留至少選 2 個候選行動的限制，因為方案評估需要比較基準。
6. 候選行動選完後，需要按「確認候選行動，進入方案評估」，方案評估表才會顯示。
7. 修正總分欄位錯誤，總分只會顯示數字或「尚未完成」。
8. 保留 V21 功能：
   - 方案評估表
   - 評分採 1／3／5 分
   - 五個構面的評分說明
   - 同分時依序比較：效益 → 可行性 → 成本 → 風險性 → 測試性
   - 最終只產出一個當選方案
   - COC 商圈活動脈絡策劃表
   - Action Design 表
   - PDF 匯出／列印
   - Pizza Hut logo
   - 後台查看／刪除／下載 CSV
   - 後台只保存完成第四階段後的有效資料
